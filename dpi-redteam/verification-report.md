## Data-quality issues found during verification

The re-verification surfaced several systematic defects in the original dataset and one tooling incident, all now resolved in the verified output:

- **Exhausted search credits mid-run.** Part-way through the Medium tier, the Exa free-tier search credits were exhausted, and a run of Registries (and a few ICT) batches came back unverified — the agents correctly preserved the original scores and flagged every affected row for human review rather than guessing. Once credits were topped up, **26 affected batches were re-run from scratch** with live source fetches. The final dataset contains only 3 residual single-row "could not retrieve the specific figure this session" caveats (South Africa smartphone penetration, Zimbabwe data-centre presence, Morocco digital-pay active users), each already flagged for human review.
- **CSV quoting corruption.** Seven Medium files initially written by the verifier contained an unescaped double-quote in a `revision_notes` field, which misaligned that row's columns. Ten rows were affected across Data-Exchange (MWI, TUN), Digital-Pay (EGY, MOZ, MUS) and ICT (GNQ, SEN). All were re-run with strict CSV formatting and the files now parse cleanly (verified: every file's Variable Id set matches its batch exactly).
- **Republic of Congo / DR Congo source mix-up.** For Congo (COG), the originally cited sources across several Digital-Pay and ICT rows actually described the Democratic Republic of the Congo (COD). Flagged by the verifier and re-sourced to genuine Republic-of-Congo references.
- **A recurring dead/irrelevant citation.** The URL `we.hse.ru/en/irs/cas/passao`, cited across many Angola rows, is a broken page unrelated to Angola; it never supported any score and was dropped in favour of primary sources.
- **False-positive triage flags.** A number of rows the triage marked `claim_no_source` in fact had valid, verifiable sources (seen earlier in the High tier for South Africa and Mauritania Registries); these were verified against the existing sources rather than treated as unsupported.
